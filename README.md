# Reportes de importación de LimeSurvey

[Consultar los reportes en el navegador](https://jjkid.github.io/form-builder-reportes-importacion/).

Resultados de la conversión del 8 de octubre de 2026 de 148 encuestas del C3 y 37 de una segunda cuenta. Los HTML incluyen filtros, causas y preguntas originales como JSON. Cada carpeta conserva el CSV y JSON descargables y su nota de verificación; los enlaces entre reportes mantienen sus rutas relativas.

Sólo se incluyen definiciones y resultados de conversión. No se incluyen respuestas de participantes ni credenciales. Los HTML, CSV y JSON se conservan sin modificaciones respecto a la evidencia local seleccionada.

GitHub Pages publica desde la raíz de la rama `main`. `.nojekyll` permite servir directamente los archivos estáticos.
